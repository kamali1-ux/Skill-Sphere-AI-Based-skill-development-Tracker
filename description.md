# PROJECT TITLE

**SkillSphere – AI-Based Skill Development Tracker**

# PROBLEM STATEMENT

Students acquire various technical and non-technical skills through courses, certifications, workshops, and projects. However, there is no centralized platform to track skill development, analyze learning progress, identify skill gaps, and receive personalized recommendations for future growth. This makes it difficult for students to monitor their career readiness and learning journey effectively.

# PROJECT OBJECTIVES

1. To develop a web-based platform for tracking student skills and learning progress.
2. To maintain a centralized repository of technical and non-technical skills.
3. To analyze skill performance using data analytics techniques.
4. To identify strengths and weaknesses in student skill sets.
5. To provide AI-based recommendations for future learning and skill enhancement.
6. To generate visual reports and dashboards for performance monitoring.
7. To support students in career planning and placement preparation.
